Anexo de [BALANCE_PVP.md](BALANCE_PVP.md). Generado el 2026-10-23 con `pnpm --dir server balance-sim --tiradas 2000`: **antes** = corrido sobre `main` (sin este cambio), **ahora** = el código con el balance implementado.

Cómo leer cada celda: **aciertos promedio para matar** `antes → ahora (objetivo)`. ⚠ marca las celdas que ahora quedan a más de 0,5 aciertos del objetivo. Las filas "golpe" del mago no tienen objetivo (el mago no pelea cuerpo a cuerpo). Perfiles de equipo: **común** = lo mejor que no es premio (crafteo, drop, misión o tienda); **set** = set de premios de canje (Desterrado, del Caído y sus versiones +1/+2/LEGENDARIA, siempre con rareza Legendaria), completado con lo común donde el set no tiene pieza.
