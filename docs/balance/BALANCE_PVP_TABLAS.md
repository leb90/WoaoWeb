Cómo leer cada celda: **aciertos promedio para matar** `antes → ahora (objetivo)`. ⚠ marca las celdas que ahora quedan a más de 0,5 aciertos del objetivo. Las filas "golpe" del mago no tienen objetivo (el mago no pelea cuerpo a cuerpo). Perfiles de equipo: **común** = lo mejor que no es premio (crafteo, drop, misión o tienda); **set** = el set de tier de la clase (Arcano, Silvestre, Templario, Paladín, Bardo, Verdugo, Silvano o Umbral, siempre Legendario), completado con lo común donde el set no tiene pieza. El cazador no tiene set: con "set" usa su equipo común y se lo mide como tal.
